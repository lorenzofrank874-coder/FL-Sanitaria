FL SANITARIA - APLICACION WEB INSTALABLE

Contenido:
- index.html: aplicación FL Sanitaria (mantiene la clave localStorage flsanitaria_jobs_v1)
- manifest.webmanifest: nombre, icono y modo de instalación
- sw.js: caché para abrir la aplicación sin conexión después de la primera carga
- icon-192.png e icon-512.png: iconos de la aplicación

PUBLICACION:
Subir TODOS los archivos de esta carpeta a la raíz de un repositorio de GitHub y activar GitHub Pages desde Settings > Pages. La dirección debe ser HTTPS.
Después abrir esa dirección en Chrome Android > menú ⋮ > Instalar aplicación / Añadir a pantalla principal.

IMPORTANTE SOBRE LOS DATOS:
El almacenamiento del archivo local (file://) y el de la web (https://) son espacios distintos. Antes de cambiar, exportar una copia desde la aplicación antigua. Después de abrir la versión web, usar Importar copia para recuperar los trabajos.
Los datos de la aplicación no se sincronizan automáticamente entre dispositivos. Mantener copias de seguridad periódicas.
